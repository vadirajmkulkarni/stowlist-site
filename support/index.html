Items and places

How does Stowlist remember where something is?

Add an item to your library and enter its place, such as “Entryway · top drawer”. Add a note or photo if helpful. Search the library to find the saved detail, and update it when the item moves. Stowlist uses the location label you enter; it does not use GPS, Bluetooth trackers, or automatic object detection.

Do I need to add a photo?

No. A name and place can be enough. If you select a photo, Stowlist keeps a copy in its local app storage. Photos are included in a portable export when you choose to make one, and are excluded from Firebase cloud backup.

Does deleting a photo in Stowlist erase my original?

The app’s stored copy and the original image in your photo library are separate. Removing or replacing an item photo triggers cleanup of unused app copies after the change saves. If cleanup fails, an unused copy can remain until later cleanup or successful all-data deletion. Deleting Stowlist data does not delete your original photo-library image. Manage that original separately in Photos.

Reusable checklists

How do I use a list again?

Create a checklist and add the things you need, linking saved items when useful. Start the list for an outing and mark each entry packed or skipped for this time. When you are ready to use the list again, start fresh. Its entries remain in place.

Does skipping an item remove it from my list?

Skipping is for the current run. It lets you set an item aside for this outing while keeping it available next time. Remove an entry only when you want to change the reusable list itself.

Can I use Stowlist without internet?

Yes. The item library, selected photos, search and checklists work locally. Cloud backup and restore, purchase validation if offered, and opening support links need an internet connection.

Backup, export and restore

What is the difference between an export and cloud backup?

In Settings, Export portable backup creates a file containing your Stowlist data, including stored photos. Save it somewhere safe and use Import portable backup to bring a compatible file back. Save cloud copy creates a manual Firebase backup of text, checklist and location-label metadata only. It does not include photos and depends on the current anonymous device identity.

Can I restore cloud backup on another phone?

Cross-device recovery is not guaranteed. Stowlist does not offer email/password sign-in. The manual cloud copy is tied to an anonymous app-specific identity on the original device. That identity may be lost after reinstalling, resetting or erasing data. Use a portable export if you need a copy you can move yourself.

Why did my restored cloud data not bring back photos?

Photos are excluded from Firebase backup. Use a portable export with photos for a fuller transferable copy. Restore cloud copy may replace local metadata, so make an export before replacing information you want to keep.

What if a backup or deletion fails?

Check your internet connection and try the cloud action again. Read the result shown in the app. Do not treat a spinner or an attempted action as a completed backup or deletion. If the problem continues, contact support with the visible error and app version, without sending private library contents.

Purchases and availability

Is Stowlist available on the App Store?

Stowlist is being prepared for iPhone. We will add a verified App Store link to the home page when it is publicly available. This website does not confirm Apple review approval or public release.

What is Stowlist Plus?

Plus is planned as an optional one-time purchase for cosmetic themes. No current price or purchase availability is promised here. If enabled, Apple will display the local price before you confirm. Core item and checklist features do not depend on buying cosmetic themes.

Does restoring a purchase restore my items?

No. Purchase restoration and data restoration are separate. If purchasing is available, use Restore purchases with the Apple account used for the purchase to restore eligible theme access. Use your own export or the app’s manual cloud restore for your item and checklist data. Apple handles refund requests.

Privacy and deletion

How do I delete my data?

In Settings, Delete cloud copy and guest account removes the cloud copy and guest identity while keeping local data. Delete all Stowlist data deletes the cloud copy and guest identity first, then erases local app data. A cloud failure preserves local data so you can retry. Use these controls while the original device identity is accessible. Uninstalling alone does not delete cloud data. Follow the data-deletion guide for details and limitations.

Do you use advertising or track what I pack?

We have not added in-app advertising, Firebase Analytics, or item/checklist behavior analytics. Optional Firebase services can process technical information and operational diagnostics. If purchases are enabled, Apple and RevenueCat process purchase information. Read the privacy policy for the complete explanation.
